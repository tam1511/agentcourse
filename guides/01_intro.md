# 01 — Giới Thiệu: Cách Dùng Repo Này Hiệu Quả Nhất

## Repo này dùng để làm gì?

Đây là kho tài liệu **tham khảo**, đi kèm khoá học video trên Udemy. Bạn không bắt buộc phải đọc hết trước khi học — hãy dùng theo cách sau:

1. **Trước khi học** → làm theo [`setup/`](../setup/) để chuẩn bị môi trường.
2. **Trong khi học từng tuần** → mở README của thư mục `weekN_.../` tương ứng để xem danh sách bài học, thời lượng và ghi chú.
3. **Khi gặp khái niệm lạ hoặc bị stuck** → tra trong thư mục `guides/` — mỗi file giải quyết một câu hỏi cụ thể.

## Sơ đồ tư duy toàn khoá học

```
Tuần 1-2: n8n (No-code)          →  Hiểu BẢN CHẤT của Agent: model + tool + memory
Tuần 3:   OpenAI Agents SDK       →  Chuyển sang viết Agent bằng CODE
Tuần 4:   MCP                     →  Kết nối Agent với THẾ GIỚI BÊN NGOÀI (data, API)
Tuần 5:   LangGraph               →  Kiểm soát WORKFLOW phức tạp, nhiều Agent phối hợp
```

Mỗi tuần không phải một công cụ tách biệt — chúng là các lớp (layer) khác nhau của cùng một hệ thống AI Agent. Học xong 5 tuần, mục tiêu không phải là "nhớ 5 framework", mà là **hiểu bản đồ tư duy** để khi gặp bài toán mới, bạn biết chọn đúng công cụ.

## Cách học hiệu quả

- Luôn **chạy code thật** — đừng chỉ xem video. Học Agentic AI mà không code giống như học bơi mà không xuống nước.
- Khi Agent chạy lỗi, đọc kỹ traceback / trace dashboard trước khi hỏi — hầu hết lỗi setup được liệt kê trong [`08_troubleshooting.md`](./08_troubleshooting.md).
- Làm capstone project cuối mỗi tuần cẩn thận — đó là lúc kiến thức thực sự "dính" lại.
- Không cần thuộc lòng cú pháp — quan trọng là hiểu khái niệm (Agent, Tool, State, Memory, Handoff...), cú pháp có thể tra lại bất cứ lúc nào.

Chúc bạn học vui!
